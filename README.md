# Australian Accommodation and Tourism

An interactive data visualisation exploring Australia’s accommodation industry through domestic recovery, international demand, rental supply and hotel occupancy.

## View the visualisation

https://sa-mue1.github.io/australian-accommodation-visualisation/
(When you open make sure its set to 100% zoom)

## About the project

Created for FIT3179 for DV II assignment.

The visualisation investigates how accommodation demand differed across accommodation types, locations and seasons. Each chart identifies its relevant period and measurement.

This website has 11 charts in total that detail the accomodation across australia with use of interative features and more.

## Tools

- HTML and CSS for page structure and styling
- JavaScript for embedding charts and supporting interactions
- Vega-Lite and Vega-Embed for visualisations
- CSV and TopoJSON for data and geographic boundaries
- GitHub Pages for hosting

## Repository structure

- `index.html` contains the page content and chart containers.
- `style.css` controls the layout, typography and styling.
- `js/vega_lite_vis.js` embeds the charts and supports interactions.
- `.vg.json` files define the visualisations.
- `data/` contains the prepared datasets.
- `data/geo/` contains geographic boundary files.

## Data sources

- Tourism Research Australia
- STR Australian Accommodation Monitor
- Inside Airbnb
- Australian Bureau of Statistics
- Vega Datasets for the world basemap

Full references are provided on the website.

## Viewing locally

Open the repository in Visual Studio Code and run `index.html` using the Live Server extension. A local web server is needed to load the data files correctly.
